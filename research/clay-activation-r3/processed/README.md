# R³ modelling datasets: calcination vs milling

Generated by `scripts/build_datasets.py` from **`r3_unified_dataset.csv`** (268 rows, calcination + milling, all with a 7-day R³ heat value). The 17 mechano-thermal (MTA) rows and the 125 Bahhou 2026 rows were removed from the repository.

```
python3 scripts/build_datasets.py research/clay-activation-r3/r3_unified_dataset.csv research/clay-activation-r3/processed
python3 scripts/consistency.py research/clay-activation-r3/processed
```

The full column-by-column documentation (meaning, unit, role, missing values) is in the [root README](../../../README.md#-final-modelling-datasets-calcination--milling).

### Why this source file
`r3_unified_dataset.csv` contains everything in the Excel file `TA_MCA_MTA_R3_XRF_QXRD_20261111.xlsx` (same R³ values for shared sample IDs) **plus**: Marsh et al. 2026 / S01 (48 milling rows), Zunino & Scrivener 2024 (12), Panzer 2024 / S03 and Koutsouradi 2024 / S02 with temperature and mineralogy, and 10 more Mañosa rows. The former `r3_measurements.csv` and `r3_auxiliary_measurements.csv` were deleted: all their 7-day heat values are in this file.

## Missing values set to 0 (known zeros)
- Exported minerals (kaolinite, illite/mica, quartz, calcite): 0 when the source mineralogy is complete (sum of all quantified phases ≥ 94 %, excluding nominal non-XRD mixtures).
- `kaolinite_pct`: 0 for pure 2:1 reference minerals (Zhao illite / montmorillonite, Marsh montmorillonites, Plusquellec illite, Koufany Ref1/Ref2).
- `grinding_aid_tea_wt_pct`: 0 when no grinding aid is reported.
- Plusquellec "Kln" (Merck reference kaolinite): theoretical kaolinite composition (kaolinite 100, SiO2 46.5, Al2O3 39.5, LOI 14.0), entered in `r3_unified_dataset.csv`.
- Everything else (oxides, process settings, minerals from a partial mineralogy) stays empty: not measured, not zero.

## Columns

**Shared**: `sample_id`, `parent_clay_id` (grouped-CV key: same publication + same raw composition), `reference` (filtering / leave-one-source-out; source details: join `r3_unified_dataset.csv` on `sample_id`), raw mineralogy (`*_pct`), oxides.

**Calcination**: `calcination_temp_c`, `dwell_min`. Calcination with a dwell only (static laboratory furnaces, one pilot rotary kiln): no flash calcination.

**Milling**: `milling_time_min`, `mill_rpm`, `ball_to_powder_ratio` (all laboratory planetary mills), `grinding_aid_tea_wt_pct` (TEA; 0 if not reported).
Extracted variables (`mill_rpm`, `ball_to_powder_ratio`, TEA) come from the sample codes first, then from the notes of each row. `notes` and `composition_method` are not in the output files: find them in `r3_unified_dataset.csv` via `sample_id`.

**Target**: `r3_heat_7d_j_per_g` (J per g of SCM, 7 days, 40 °C).
- R³ value quality (exact / read from a figure / derived): column `R3 data quality` of `r3_unified_dataset.csv`. Tested: neither weighting nor filtering by quality improves grouped cross-validation.

## Columns removed after testing (grouped cross-validation by clay)
`post_d50_um` (no gain; in milling it is an outcome of milling, i.e. leakage), `na2o_pct`, `tio2_pct`, `milling_energy_kwh_per_kg` (3 clays, made the error worse), `smectite_pct`, `mixed_is_pct`, `chlorite_pct`, `dolomite_pct`, `feldspar_pct`, `other_minerals_pct`, `raw_amorphous_pct`, `total_clay_pct`, `furnace_type`, `cooling`, `mill_type` (single value), `r3_quality`. They all remain in `r3_unified_dataset.csv`.

## Points of attention
- Bahhou 2026 (S22, 125 rows) removed: secondary compilation without per-row primary sources, values > 1000 J/g and contradictory pairs; in grouped CV, adding it raised the RMSE on the other sources from 161 to 188 J/g.
- Marsh 2026: no raw composition published, neither in the paper nor on Zenodo (K = kaolinitic clay, Mt = montmorillonitic, F = mixed clay; Mt = "T2" on Zenodo). All 54 measurements of the Zenodo dataset are covered (48 rows: the other 6 repeat the reference condition 550 rpm / BPR 25 / 60 min). The other 51 points of the Zenodo dataset are literature data already present (Plusquellec, Mañosa, Marsh 2024) or bound-water data (Baki 2022).
- Sources cited in `sources.json` but with no data in the repository: S04 (UR2, 47 samples with R³, XRF, QXRD), S05 (Maier, 13 clays), S08/S18 (palygorskites), S11, S12.
